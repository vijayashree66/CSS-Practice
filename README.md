# Dine Craft 🍽️

A responsive restaurant landing page built using HTML5 and CSS3 as part of my frontend practice.

## Features
- Sticky navigation bar with a services dropdown and a Reserve Table button
- Hero section with a call-to-action button
- "Our Story" section with a dining image
- Menu section with food cards in a CSS Grid layout
- "Why Choose Us" section with Remix Icons
- Dark and gold theme
- Responsive design using media queries (1100px and 650px)

## Tech Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Remix Icon
- Unsplash images

## How to Run
1. Download or clone this repo
2. Open index.html in your browser
